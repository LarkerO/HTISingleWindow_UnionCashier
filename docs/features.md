## 原需求审查结论

- 旧版站内文档只展开了普通下单示例。退款、预授权、免密签约／扣款已存在，本次补齐文档并新增商户主动解约和稳定错误码。
- 旧收银台只提供一个备用位置。本次加入可排列的多项备用方式，最多选择八项。
- 当前 Portal 实现通过公开 Minecraft 档案接口同步 UUID。Portal 禁用公开档案时，玩家仍可登录，游戏钱包等待可用的已验证档案。
- 商户 API 与游戏 WebSocket 走 SM2/SM3 应用层报文。网页及 OAuth 使用 HTTP(S)，公网部署可通过 HTTPS/WSS 代理保护浏览器会话。浏览器也可以通过预付卡完成适用场景的支付。
- 当前后台以一个已登记、验证通过的游戏插件作为权威执行端。服务端版本兼容性和各数据库的生产环境验收分别执行。
- 清算假期日历和旧退款的逐笔时间属于当前实现限制。旧退款账单用已有累计数据展示。
